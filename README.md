# Amazon Sales Dashboard 📊

## Project Overview
This project is an interactive Amazon Sales Dashboard developed using Microsoft Excel. It provides insights into sales performance, revenue, customer orders, product categories, and payment methods across different countries.

## Dashboard Preview

![Amazon Sales Dashboard](Screenshot%202026-11-04%20163821.png)

## Tools & Techniques Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Cleaning
- Data Visualization

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value (AOV)
- Cancellation Rate
- Return Rate

## Key Business Insights
- United States generates the highest revenue.
- Electronics is the highest revenue-generating product category.
- 29,795 orders were successfully delivered.
- The order cancellation rate is approximately 3%.

## Dashboard Features
- Interactive Country, Category and Year slicers.
- Monthly Sales Trend Analysis.
- Revenue Analysis by Country.
- Sales Analysis by Product Category.
- Top 10 Products Analysis.
- Order Status Analysis.
- Payment Method Analysis.

## Project Objective
The objective of this project is to transform raw sales data into meaningful business insights through an interactive Excel dashboard, supporting better business analysis and decision-making.
